# Digital-Edition-CLM10058
Projektbeschreibung
Dieses Repositorium enthält die digitale Teiledition des 14. Buches „De Terra“ aus den Etymologiae des Isidor von Sevilla, überliefert in der Handschrift CLM 10058 der Bayerische Staatsbibliothek.

Die Edition entstand im Rahmen meiner Masterarbeit im Bereich der Digital Humanities und Geschichte an der Universität Paderborn. Ziel des Projektes war es, sowohl den Handschriftentext (folio 154r–165v) als auch die im Text eingebundene Mappa Mundi (mittelalterliche Weltkarte) zu edieren, digital zu erschließen und online verfügbar zu machen.

Editionsgrundlagen
Textedition: Die Transkription des Handschriftentextes basiert auf der Edition von W. M. Lindsay (1911).

Kartenedition: Die Transkription der Mappa Mundi folgt der Edition von Patrick Gautier Dalché (1988).

Daten und Struktur
Das Projekt umfasst mehrere XML-Dokumente (TEI-konform):

XML-Dateien zur allgemeinen Nutzung in beliebigen XML-Editoren

Speziell für die Darstellung im TEI Publisher angepasste XML-Dokumente

ODD-Dateien (Dokumentations- und Schemamodellierung)

Template-Dateien für die Publisher-Darstellung

Projektzeitplan

Transkriptionsdateien

Für die Entwicklung wurde der Oxygen XML Editor verwendet.

Die nicht auf den Publisher zugeschnittenen XML-Dateien enthalten vollständige IIIF-Verknüpfungen zu den Digitalisaten. Die Publisher-Dokumente müssen mit dem jeweiligen Template und der zugehörigen ODD-Datei kombiniert werden, um die Bildanzeige korrekt darzustellen. Die Konfiguration ist speziell auf den TEI Publisher abgestimmt. Die Edition wurde für den TEI-Publisher 7.1. entwickelt. Neue Versionen der Software können Anpassungen notwendig machen.

Other (English)
Project Description
This repository contains the partial digital edition of Book XIV (De Terra) of the Etymologiae by Isidor von Sevilla, preserved in manuscript CLM 10058 at the Bayerische Staatsbibliothek.

The edition was created as part of a Master's thesis in the field of Digital Humanities. The project aimed to edit, digitally encode, and publish both the manuscript text (folio 154r–165v) and the Mappa Mundi (medieval world map) embedded in the text.

Editorial Basis
Text edition: The transcription of the manuscript text is based on the edition by W. M. Lindsay (1911).

Map edition: The transcription of the Mappa Mundi follows the edition by Patrick Gautier Dalché (1988).

Data and Structure
The project consists of several TEI-conformant XML documents:

XML files designed for use in any standard XML editor

XML files specifically adapted for presentation in TEI Publisher

ODD files (schema customization and documentation models)

Template files for TEI Publisher visualization

Project timeline

Transcription files

Development was carried out using the Oxygen XML Editor.

The XML files not specifically prepared for TEI Publisher include complete IIIF references to the digitized manuscript images. The Publisher-oriented documents must be combined with their respective template and ODD files to correctly display images. The configuration is specifically tailored to TEI Publisher. The edition was developed for TEI Publisher 7.1. New versions of the software may require adjustments.

Availability
